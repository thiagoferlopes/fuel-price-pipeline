## Extract.py

1. __Padrão de URL__: O site da ANP expõe um link no formato: ``https://www.gov.br/anp/pt-br/centrais-de-conteudo/dados-abertos/arquivos/shpc/dsas/ca/ca-{ano}-{semestre}.csv`` até o 2° semestre de 2021, a partir do 1° semestre de 2022 os arquivos mudaram de formato para `.zip`. Vou precisar gerar essa URL com essa URL com extensão .zip para cada ano entre 2022-01 e 2026-01, substituindo {ano} e {semestre} no loop. Além disso, tivemos uma incossitência no padrão de nomeclatura da URL do semestre de 2022.01, podendo se tornar mais um obstáculo ao extrair os arquivos, esse link não segue padrão de nome versionado dos demais, existe risco de o conteúdo mudar sem aviso, sem consulta futura.

2. __Local de Salvamento__:Cada arquivo baixado vai para ``data/raw/ca-{ano}-{semestre}.zip``, tendo que realizar uma descompactação, antes de seguir para Tranformação, convertendo esse arquivo em CSV. O ano e o semestre no nome evita que um download sobrescreva o anterior sem eu perceber. Além disso deverá retornar uma mensagem ao concluir o script, com a pasta que ela foi enviada.

3. __Comportamento em 404__: Se um semestre não existir no servidor, o script registra no log qual ano e o seu semestre falhou e continua para o próximo, não parando a execução inteira. 
Justificativa: Se ocorreu algum problema na execução do script para download dos arquivos, não quero que o programa falhe totalmente, guardando o ano e o semestre desse arquivo nos logs, para verificação manual ao final do script.

4. __Comportamento de Queda de conexão no meio do download__: Primeira vez que eu particulamente penso nisso. Minha ideia é: caso ocorra algum erro de conexão, o arquivo parcial não fique salvo no lugar de um arquivo completo. Decisão: Baixar com  nome temporário e renomear para o nome final só após o downlaod terminar por completo, evitando que um arquivo parcial seja confundido com um completo.
